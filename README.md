
# Never talk to girls

A small prototype of a comedy game where the player asks out girls at a club and gets terribly rejected. Made for the 7 day long Brakeys Game Jam 2025.2


## Demo

You can play the full prototype on itch.io with this link https://thejoeman23.itch.io/never-talk-to-girls


## Features

- __Fully voice acted branching dialogue__ _(made with a custom node based dialogue editor)_
- __24__ different endings
- __6 Unique NPCs__
- 3rd Person Movement
- Pause menu
- Disco floor
- Small tutorial

- Indicators marking what branches of dialogue you've already done
- The ability to skip dialogue you've already heard
- Several small bugs which have since been patched
